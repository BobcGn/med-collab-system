# UNet 训练验证与结构化分割服务

## 职责与已确认范围

Python 服务拥有影像解码、模型预处理与执行、mask 后处理、质量门禁及分割工件，不拥有业务账号、患者档案、报告定稿或自由问答。跨服务契约归 `med-collab-architecture`，医疗权限边界归 `hospital-ai-boundary`。

用户确认个人课程作业需要独立完成训练、评测、模型导出和平台推理闭环，不依赖研究生的模型交付；这是一项已确认的目标，不是现有能力声明。当前仓库具有推理代码，尚无完成该闭环的训练流程和真实数据评测证据。

个人作业与正式 Agent 建设分别在独立分支进行。合并顺序是用户的工作安排，不改变服务契约，也不表示课程模型自动获得医院使用资格。具体数据集、模态/器官、数据许可、训练设备、课程评分标准与效果阈值均未确认，本规格不擅自固定这些选择。

## 现有输入与模型契约

单张与顺序批量接口接收 JSON；LOCAL_FILE、DATA_URL 和 HTTP(S) OBJECT_STORAGE 最终均由 Pillow 解码为单张栅格图。INLINE_REFERENCE 没有像素，执行时拒绝；尚无原生 DICOM、体数据、HU 窗宽窗位、物理间距/方向读取或多帧处理能力。Python 模态字段本身只要求非空并转大写，不会像 Kotlin 正式入口一样拒绝 OTHER。

当前预处理固定为灰度、双线性拉伸至配置尺寸、缩放到 [0,1] 后归一化到 [-1,1]；多通道是复制灰度，不是真实 RGB。输出概率经 8-bit 图像转换后恢复到原图尺寸再阈值化。训练与推理不一致会造成无效结果，不能仅凭 tensor 形状相同认定兼容。

加载器固定构造仓库内 UNet2D（四级下采样、Conv/BatchNorm/ReLU、转置卷积与 skip 连接）；本地默认输入为 1×256×256、base_channels=32、单输出。接受原始 state_dict 或 state_dict / model_state_dict 包装，严格匹配键和形状；不支持任意网络权重、TorchScript 或 ONNX 自动适配。

单输出取 sigmoid，多输出 softmax 后只取一个配置的 lesion 通道，类名固定为 lesion；当前不是多类别结构化分割系统。默认允许无权重随机前向，mock 也可显式选用。weights_loaded 仅证明加载成功，不能证明权重训练来源或精度；请求设备不可用时可能退到 CPU。

## 输出的真实含义

后处理按连通域生成覆盖率、百分比坐标边界框、采样轮廓与平均前景概率。毫米尺寸使用全局配置的像素间距，图像象限用于位置描述，severity 来自概率/覆盖率规则；这些不是患者特异的物理标定、解剖定位、置信度校准或临床风险模型。轮廓采样也未证明能保留全部拓扑。

质量门禁对空 mask / 无区域返回 FAIL，低置信度或单区域覆盖过大返回 LIMITED，其余 PASS；PASS 不检查真实训练来源，随机/mock 输出也可能通过。结果状态与 HTTP 状态不同：质量失败仍可通过 HTTP 200 返回 failed payload。

默认保存 mask、overlay、result.json，即使质量门禁失败也可能产生工件。return_contour 生效，但 return_mask / return_metrics 当前未完整执行；被过滤小区域也可能仍留在 mask 工件中。模型名、版本、耗时与加载状态已有，但缺少完整预处理记录、checkpoint 哈希/训练来源和可重现配置。/health 不验证模型就绪，模型通常在依赖首次解析时才初始化。

## 训练与评测验收语义

从用户确认的训练—评测—推理闭环推导，以下为待审阅的验收约束，而非已完成事实：

- 使用许可允许的影像/标注，能重现数据划分、训练配置和最佳权重选择；评测集不得用于训练，医学样本的患者级泄漏需检查。
- 以分割指标（拟采用 Dice / IoU，未确认）及影像—标注—预测可视化检验真实训练效果，不以随机权重前向或 mock API 测试代替精度证据。
- 导出物需能说明网络结构、通道、尺寸、归一化、类别和阈值；同一输入在离线推理与服务端预处理/输出语义一致。
- 无可靠物理标定时不得把像素测量当作已验证毫米测量；无标定的置信度与规则化风险不能被包装成临床结论。

## 已知安全与运行限制

输入缺少明确的字节/像素/批量限制、本地目录和远程 URL 白名单及服务鉴权；request_id 直接参与工件目录，存在路径逃逸与覆盖风险。配置的推理超时尚未落实到执行取消，批量异常可中止整批；工件可能含患者身份信息，不能公开暴露路径或把真实患者资料直接用于课程实验。

现有测试覆盖合成 mask、mock API、随机权重前向与形状；没有真实训练 checkpoint 加载与精度回归证据。本次规格初始化未运行这些测试，也未验证训练结果。
